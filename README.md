```markdown
# 設備保全ドキュメントで作る RAG ハンズオン

Snowflake Cortex Search を使って、PDF の非構造化データ（テキスト＋画像）から検索・回答できる RAG を構築するハンズオンです。

## 使い方

1. `01_text_rag.ipynb` をダウンロードする（ファイルをクリック → 右上のダウンロードボタン）
2. Snowflake にログインし、ワークスペースに Notebook をアップロードする
3. Notebook を上から順に実行する（PDF は Notebook 内の手順で自動取得されます）

## 内容

| 章 | 内容 |
|---|---|
| 0 | 環境準備（データベース、ステージ、GitHub からデータ取得） |
| 1 | テキスト RAG（PDF 解析 → チャンク化 → Cortex Search → 回答生成 → CoWork） |
| 2 | マルチモーダル RAG（画像抽出 → Vision LLM でキャプション → 画像も検索対象に） |

## データ

`data/` フォルダには以下の PDF が含まれています（合計 23 件、約 94 ページ）。

- **A**: 経産省「スマート保安先行事例集」抜粋（23p）
- **B**: 厚労省「機械設備のリスクアセスメントマニュアル」抜粋（26p）
- **C**: 厚労省「職場のあんぜんサイト」労働災害事例 20 件（40p）
- **D**: Snowflake 設備保全データ活用スモールスタートガイド（5p）
```
